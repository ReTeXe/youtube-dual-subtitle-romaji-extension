# YouTube Dual Subtitles + Japanese → Romaji Converter

A Chrome extension that enhances YouTube subtitles for Japanese learners:

- Converts Japanese subtitles into Romaji (Latin alphabet)
- Adds a second subtitle line (e.g., Turkish, English, etc.)
- Helps you learn Japanese faster while watching videos

## ✨ Features

- 🇯🇵 Japanese → Romaji conversion (Hiragana, Katakana, Kanji)
- 🌍 Dual subtitles (Japanese + your language)
- ⚡ Real-time subtitle processing
- 🎯 Designed for language learners

## 🚀 Installation

1. Clone the repository
2. Go to `chrome://extensions/`
3. Enable Developer Mode
4. Click "Load unpacked"
5. Select the project folder

## 🧠 How it works

- Detects YouTube subtitle elements
- Extracts Japanese subtitle text
- Converts it into Romaji
- Fetches or injects a second subtitle (e.g., Turkish)
- Displays both in sync

## 📦 Tech Stack

- JavaScript
- Chrome Extension API
- DOM manipulation
- Subtitle parsing
